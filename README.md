# 🌐 Portfólio Pessoal

Este é o meu portfólio pessoal, desenvolvido com o objetivo de apresentar minhas habilidades, projetos e informações profissionais de forma organizada e responsiva.

O projeto foi criado utilizando apenas **HTML5** e **CSS3**, com foco em boas práticas de estruturação, estilização e experiência do usuário.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

## ✨ Funcionalidades

* Design moderno e responsivo
* Seção de apresentação
* Sobre mim
* Habilidades técnicas
* Projetos desenvolvidos
* Informações de contato
* Navegação simples e intuitiva

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para servir como meu portfólio profissional, reunindo os principais trabalhos que venho desenvolvendo durante meus estudos em desenvolvimento web.

Além de apresentar meus projetos, ele demonstra minha evolução na criação de interfaces, organização de código e desenvolvimento de páginas responsivas.
